# Demonio MT940

Demonio en Python que procesa automáticamente archivos bancarios en formato **MT940**, detectando su llegada mediante `inotify` (sin consumo de CPU en reposo), generando archivos **JSON** estructurados y ofreciendo un **servidor SSL local** para recepción segura de datos.

Proyecto desarrollado durante las prácticas profesionales de Ingeniería en Computación.
